# Weather Data Analysis & Machine Learning

## Overview

A data science project exploring weather patterns and relationships between temperature, precipitation, and wind. Used Python to clean and analyze weather data, apply statistical methods, and build machine learning models to identify trends and make predictions.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy

## Project Work

- Performed data cleaning, exploratory data analysis, and visualization.
- Applied statistical analysis to investigate relationships between weather variables.
- Developed machine learning models to predict weather conditions and identify patterns.
- Explored time-series data to examine weather trends over time.
